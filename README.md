# ResumeCraft AI - 100% Free ATS Resume Builder

## Description
ResumeCraft AI is a free, real-time split-screen resume builder designed to create highly polished, ATS-optimized resumes with zero signups. Build professional, parser-proof resumes in real-time, choose from premium templates, let AI refine your content, and download instantly without leaving your browser.

## Features
- **Parse-Ready Formatting:** Clean HTML structure, standard fonts, and semantic headers that Applicant Tracking Systems expect.
- **Real-time Live Preview:** See exactly how your resume updates as you type. Adjust styling, margins, and layouts instantly.
- **100% Offline Privacy:** Your details never touch our servers. All information stays locally inside your own browser.
- **AI Writing Helper:** Instantly rewrite passive phrases into strong action items, or hook up your API keys for real AI enhancements.
- **Backup & Restore:** Export your details as a lightweight JSON file. Load it back up anytime to update your experience.
- **Perfect Print Export:** One-click print CSS compiles to a beautiful, clean, alignment-perfect PDF file on A4 or Letter sizes.
- **External ATS Resume Auditor:** Paste your existing resume text or upload a file to analyze keyword density, section parsing, power verbs, and ATS compatibility score.

## ATS Templates Available
- **Classic Executive:** Traditional, corporate layout. Best for Finance, HR, and Management.
- **Modern Sidebar:** Elegant two-column design. Best for Marketing, Sales, and Consultants.
- **Minimal Clean:** Ultra-readable, high contrast spacing. Best for senior roles and simplicity.
- **Bold Professional:** Strong headers and visual emphasis. Best for Operations & Project Managers.
- **Developer Syntax:** Monospace accents, git green notes. Best for Engineers & Devs.
- **Creative Gradient:** Sleek design with subtle header styling. Best for Designers & Creatives.
- **Academic Blue-Header:** Solid blue headers and clean academic formatting. Best for Students & Researchers.

## Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, Grid)
- Vanilla JavaScript
- LocalStorage for autosave functionality
- Third-party Parsing Libraries: PDF.js, Mammoth.js, Tesseract.js

## Usage
Simply open `index.html` in your modern web browser to start building your resume.
